# Night Shift — личный проверочный стенд, версия 1.2.0

Назначение: проверять Simply Localize как обычная игра-потребитель. Не распространяемый Sample. Единственный рабочий исходник находится в playgrounds/SimplyLocalize-Lab/Assets/HorrorLab.

**Главное правило:** стенд не исправляет и не прячет ошибки плагина. Ограничения записываются в [журнал](../../../../docs/playground-journal/night-shift/README.md).

## Запуск и настройки

Рабочая сцена: Assets/HorrorLab/NightShiftMenu.unity. Войти в участок → Вернуться в игру. WASD / мышь без ПКМ / E / F / Tab / Esc. Взаимодействия выбираются перед героем, надписи осматриваются отдельно. Потеря фокуса освобождает курсор; повторный захват только по явной кнопке.

Текст: en/ru/pl; голос: en/ru; визуальные ассеты: en/ru/pl. Языки независимы. Текст меняется в паузе, голос и визуальный язык — перед входом. Перевод надписей: Выкл./Авто/Всегда; субтитры отдельно. Польская предупреждающая табличка намеренно использует английский fallback.

## Что делает игра

- Контроллер меняет игровые состояния и сообщает ID диалога.
- UI запрашивает строки у одного постоянного LocalizationManager; SetLanguage, fallback, форматирование и кэши остаются в плагине.
- Контекст мира содержит два менеджера плагина, но не собственный кэш ресурсов.
- Представление запрашивает визуальный вариант при подключении мира; диалог запрашивает AudioClip при воспроизведении.
- Метаданные фактического языка таблички хранятся в авторском HorrorVisualVariant. Это модель контента для функции «Авто», а не дублирование fallback.
- При выходе игра останавливает AudioSource, снимает подписки, отсоединяет представление, выгружает свою сцену и убирает свои ссылки. Очисткой ресурсов локализации она не занимается.

**Удалено:** UnloadUnusedAssets, ClearCaches, ручной LoadAudioData, прогрев глифов, менеджер-кандидат при каждой смене текста, собственные словари подготовленных клипов/вариантов, подмена пустого текста для тяжёлых каналов. Ни один из этих обходов не используется и в новой проверке.

ObservedResourcesProvider только считает и без изменения пересылает все вызовы стандартному ResourcesDataProvider. Счётчик не является полной трассировкой диска: глобальный bootstrap плагина проходит мимо него.

IHorrorWorldPreparer вызывает штатные PrepareLanguage/ApplyPreparedLanguage для голосового и визуального менеджеров до публикации мира. Диалоги и объекты используют ResolvePreparedAsset: получение ссылки больше не читает провайдер. Resources-подготовка остаётся синхронной; Task.Yield лишь даёт обновиться прогрессу. Dispose подготовленного снимка освобождает его ссылки, а не Unity-ресурсы. Неготовые аудиоданные по-прежнему фиксируются в отчёте. Протокол: plugin-owned-v2-prepared.

Настройки аудиофикстуры фиксированы и записываются в build identity: DecompressOnLoad, Preload Audio Data=false, Load In Background=true. Это специально делает видимым поведение первого использования. Стенд не гарантирует отсутствие задержки первого звука.

## Проверки и версии

VERSION.json — версия стенда и протокол измерений. CHANGELOG.md — изменения стенда.
Editor/HorrorBuildIdentity.cs при каждой сборке записывает версию пакета, точный Git commit/describe, состояние исходников плагина, SHA-256 runtime, исходников стенда, сцен и данных. Git должен быть в PATH редактора; иначе можно явно задать NIGHTSHIFT_GIT. Если commit недоступен, это записывается честно, но такой запуск нельзя подписывать известным commit вручную без проверки соответствия.

Editor-метод SimplyLocalize.HorrorLab.Editor.HorrorArchitectureSetup.BuildAndVerify создаёт Release-сборку и проверяет данные/взаимодействия. При открытом редакторе вызывайте через Unity CLI; не запускайте второй Unity на том же проекте. Перед процедурой сохраните сцены; для автоматизации сохраните и восстановите EditorSceneManager.GetSceneManagerSetup().

Player: Builds/NightShift/NightShift.exe с -batchmode -nographics --nightshift-benchmark --nightshift-report <абсолютный JSON> -logFile <абсолютный лог>. Автоматизация запускает скрытый процесс без захвата ввода. Профайлерный PlayerConnection не включается.

Отчёт отдельно содержит functionalChecksPassed и findings. PASS не означает, что локализатор освобождает ресурсы или подходит для гигабайт. Проверки не вызывают принудительную сборку мусора или выгрузку ресурсов для получения красивых цифр. Текущие результаты и порядок следующего запуска — в журнале; Verification — только удобная копия последнего запуска, не исторический архив.

## Хранение

Один репозиторий содержит пакет src/SimplyLocalize, проект playgrounds/SimplyLocalize-Lab и отчёты docs/playground-journal. Пакет подключён локальной зависимостью file:; исходники обоих полигонов находятся непосредственно в Assets проекта.

Копия Samples~ выведена из разработки. Прежние исходники LocalizationLab доступны в коммите d2f7795; расположение резервной копии до переноса указано в отчёте ниже. Все существующие .meta сохраняются. Новые файлы импортируются Unity перед коммитом вместе с их .meta. См. [отчёт переноса](../../../../docs/project-structure/0001-local-package-migration/REPORT.md).

Среда: Unity 6000.0.62f1, URP 17.0.4, uGUI/TMP 2.0.0, Input System 1.14.2. Генератор сцены остаётся инструментом восстановления тестовой фикстуры. Он перезаписывает демонстрационные тексты/таблицы из Content; не применяйте его к произвольному пользовательскому контенту.
