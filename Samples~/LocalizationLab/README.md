# Simply Localize: тестовый полигон

Целевая версия: **Unity 6000.0.62f1**. Эта сцена — инструмент разработки, а не часть runtime API плагина.

## Восстановление

1. Создать пустой проект Unity 6000.0.62f1.
2. Клонировать репозиторий в `Assets/SimplyLocalize`, переключиться на рабочую ветку.
3. Через Package Manager установить Unity UI (с TMP для Unity 6), Newtonsoft Json и Test Framework.
4. Скопировать содержимое этой папки в `Assets/LocalizationLab`. Папки с окончанием `~` Unity не импортирует автоматически.
5. Импортировать TMP Essential Resources через `Window > TextMeshPro > Import TMP Essential Resources`.
6. Выбрать `Tools > Simply Localize Lab > Create Playground`, затем нажать Play.

Генератор создаёт сцену, три языковых профиля, динамический TMP-шрифт из Liberation Sans и JSON-таблицы. Конфиг находится вне Resources и запускается только контроллером сцены, чтобы не вмешиваться в автоматические тесты. Повторный вызов меню открывает существующую сцену, не перезаписывая таблицы и настройки.

## Ручные проверки

| Действие | Ожидаемый результат |
|---|---|
| English / Русский / Polski | Меняются TMP и legacy Text, увеличивается счётчик событий |
| `+ 1`, `- 1`, набор контрольных чисел | Меняется число и форма существительного; отдельно проверить 1, 2, 5, 11, 21, 22 |
| Русский или польский | Строка fallback остаётся английской: ключ есть только в en |
| Любой язык | `{{name}}` и `{{0}}` отображаются как `{name}` и `{0}` |
| Русский, Toggle local override | Размер специальной строки переключается между x1.4 и глобальным x1.1; повторения не увеличивают размер |
| Switch provider | К приветствию добавляется номер ревизии |
| Bump source revision | Номер источника в статусе растёт, перевод остаётся из кэша |
| Reload | Перевод получает новую ревизию, компоненты обновляются без смены языка |
| Simulate load failure | Предыдущий текст и число событий сохраняются; ожидаемое исключение перехватывается контроллером |
| Toggle samples, смена языка, Toggle samples | Повторно включённые компоненты показывают текущий язык |
| Остановить и повторно запустить Play | Начальные язык, провайдер и счётчики восстановлены |

Регрессионные тесты плагина: `Window > General > Test Runner`, наборы `SimplyLocalize.Tests.EditMode` и `SimplyLocalize.Tests.PlayMode`. Тесты создают собственные временные данные. Не запускайте их одновременно с ручным Play-сеансом.

При установленном Unity Pipeline можно проверить реальные кнопки и компоненты сцены вызовом `SimplyLocalize.Lab.Editor.LocalizationLabChecks.Run()` через `unity command script eval`. Запускать после Start в новом Play-сеансе: проверка ожидает исходный счётчик и провайдер. Исключение означает провал проверки; успешный результат начинается с `PASS`.

Полигон не доказывает полноценную поддержку RTL, shaping арабского текста, Spine или всех платформ сборки. Для этих возможностей нужны отдельные интеграционные проверки. Версии Unity ниже 6000.0.62f1 требуют отдельного прогона.
