# NS-DOC-006 — хранение отчётов о структуре проекта

Редакция **1.1**, 2026-11-16. Каталог содержит подробные технические отчёты и минимальный комплект материалов для повторной проверки. Рабочие логи, скриншоты, временные пробы и дубли исходников удалены; фактические результаты прежних прогонов не изменены.

## Состав и назначение

| Документ | Сохраняемые материалы |
|---|---|
| [NS-DOC-004](0001-local-package-migration/REPORT.md) | NUnit XML, результат интеграционной проверки, итог миграции, базовый список GUID/SHA-256 и скрипт проверки метафайлов |
| [NS-DOC-005](0002-urp-reference-cleanup/REPORT.md) | Два исходных URP-файла для воспроизведения MIG-001, скрипт исправления, итоговые JSON проверок и сравнения |

Изначально сломанные URP-файлы сохраняются: их состояния не было в родительском Git-коммите, а без них нельзя точно повторить MIG-001. Исправленные версии находятся в Assets проекта; отдельные копии после исправления не нужны. Снимки исходников запусков, build identity, Player JSON и связанные метрики хранятся только в [журнале запусков](../playground-journal/night-shift/README.md).

Вместо PNG оставлены хеши четырёх пар кадров и методика съёмки. Это запись исторического результата, а не возможность заново просмотреть старые изображения. Повторная визуальная проверка требует новых снимков. Вместо нескольких полных файловых манифестов оставлен один baseline метафайлов; его GUID можно проверить независимо от преобразования переводов строк Git.

## Правила последующих изменений

Сохранять подробные причины, версии, ограничения, порядок воспроизведения и конечные результаты. Не копировать сюда содержимое Library/Builds/Logs/TestResults целиком. Новый артефакт добавлять, только если он необходим для воспроизведения ошибки или содержит уникальный результат, отсутствующий в другом месте репозитория.

Промежуточные команды, PID, временные скрипты и резервные копии не входят в постоянный набор. Секреты, токены и пароли исключаются из любых публикуемых материалов. Перед первым push значения -accessToken были скрыты в восьми логах; при сокращении каталога эти логи удалены из публикуемой версии целиком.

Отчёты пересматриваются с повышением редакции. Исторические значения измерений не подменяются новыми; при переносе артефакта меняется его ссылка, а не результат эксперимента. Старые исходники без Git-истории, уже сохранённые в журнале запусков, эта уборка не удаляет.
