# Этап 9.2 — ограниченный Resources и асинхронная подготовка

2026-11-16, Unity 6000.0.62f1, ветка dev/localization-stability. База 5ec24d8 плюс изменения этого этапа. Завершён следующий шаг этапа 9: явные границы источников, реальные async-запросы и закрытие провайдера. Native release остаётся отдельной незавершённой задачей.

## Изменения

Добавлены ResourcesLanguageSources и ScopedResourcesDataProvider. Списки точных адресов неизменяемые, не содержат Unity-ссылок и ничего не загружают при создании. Асинхронная подготовка использует Resources.LoadAsync по адресу; синхронные методы сохранены. Ошибка явно указанного ресурса или JSON не публикует частичное состояние. Неуказанные языки возвращают пустые данные для продолжения fallback.

Dispose закрывает провайдер для новых чтений и отменяет ожидания. Уже начатый native-запрос может закончиться позже. Общие Unity-объекты не выгружаются и не становятся недействительными у другого владельца. В этом шаге выбран явный контракт заимствования, а не неподтверждённое исключительное владение Resources. [Примеры и точные ограничения](../README.md).

Обычный ResourcesDataProvider, старый API, форматы данных, меню настройки и автозапуск не менялись. Внутренние тесты/генератор/фикстура остаются в playgrounds, не в UPM-пакете. Новый провайдер можно подключить скриптом игры без изменения пакета. Генерация набора через основное окно пока не реализована.

## Что подтверждено и чего это не доказывает

Граница между отдельными таблицами проверена в новом процессе без предварительной загрузки фикстуры. Это не холодный дисковый benchmark: ОС может кэшировать файлы. Счётчик Profiler.GetRuntimeMemorySizeLong вернул 0 для большой текстуры; этот результат не используется как доказательство нулевой памяти или измерение экономии RAM. Подтверждены отсутствие объекта до запроса и наличие объекта/размеров после положительного контроля.

SL-002 улучшен для нового opt-in провайдера: I/O использует async, но JSON-парсинг/merge и применение всё ещё выполняются на главном потоке. SL-004: отдельный сосед не загружается; прямые зависимости выбранной таблицы по-прежнему загружаются Unity. SL-005: определено безопасное закрытие провайдера, но отсутствует управляемая native-выгрузка. SL-006 воспроизводится: первые два голосовых языка Unloaded перед Play. После выходов остаётся 3/6/6 AudioClip; наличие объектов не доказывает утечку. Общие бюджеты SL-012 и большие текстовые базы пока не проверены.

Следующий шаг — готовность аудиоданных перед воспроизведением (9.3). Native release требует отдельного контракта владения/совместного использования и не считается закрытым. Addressables, файловые переводы и следующие этапы плана не затронуты.
