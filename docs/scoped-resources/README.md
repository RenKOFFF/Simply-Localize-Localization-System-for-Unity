# Ограниченная асинхронная загрузка Resources — этап 9.2

ScopedResourcesDataProvider загружает только перечисленные файлы и таблицы. Это дополнительный провайдер, который можно подключить из скрипта игры без форка пакета. Обычный ResourcesDataProvider, автоматический запуск и существующие данные не меняются. Новая настройка окна/Inspector в этом шаге не добавлялась.

## Пример

```csharp
using SimplyLocalize;
using SimplyLocalize.Data;

var provider = new ScopedResourcesDataProvider(new[]
{
    new ResourcesLanguageSources("en",
        textFiles: new[] { "Localization/en/text/menu" },
        assetTables: new[] { "Localization/en/MenuPictures" }),
    new ResourcesLanguageSources("ru",
        textFiles: new[] { "Localization/ru/text/menu" },
        assetTables: new[] { "Localization/ru/MenuPictures" })
});
var manager = new LocalizationManager(config);
manager.SetDataProvider(provider);
using (var ready = await manager.PrepareLanguageAsync("ru",
    cancellationToken: cancellation))
{
    manager.ApplyPreparedLanguage(ready, cancellation);
}

var picture = manager.ResolvePreparedAsset<Texture2D>("menu/background");
// Использовать picture.Value, если picture.Status == LocalizationResolveStatus.Found.
// После завершения работы с этим провайдером:
provider.Dispose();
```

Адреса задаются от папки Resources, без расширения файла, например Localization/en/MenuPictures. Они не привязаны к resourcesBasePath конфига: в одном наборе можно явно перечислить источники из разных разделов. Для asset-only конфига loadTextData=false; для text-only подготовки includeAssets=false. Пример использует собственный менеджер: у уже активного менеджера SetDataProvider сохраняет прежний синхронный контракт перезагрузки.

ResourcesLanguageSources копирует входные списки и предоставляет их только для чтения. Порядок файлов сохраняется: при повторяющемся ключе побеждает последний указанный файл, с предупреждением. Пустой список означает «ничего не загружать». Неуказанный язык даёт пустой результат, поэтому fallback может перейти к следующему настроенному языку. Если явно указанный адрес отсутствует или содержит неверный тип, подготовка завершается ошибкой, сохраняя прежнее состояние менеджера. Ошибки JSON содержат адрес и язык.

## Что происходит при загрузке

Async-методы используют Resources.LoadAsync по точному адресу. Сканирования папок и синхронного обходного пути нет. Unity описывает адреса как относительные Resources-пути без расширений и возвращает результат через ResourceRequest. [Документация Unity 6.0](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Resources.LoadAsync.html).

Загрузка идёт последовательно в объявленном порядке. Разбор JSON, объединение словарей и применение остаются на Unity-потоке. Это не гарантия отсутствия длинного кадра для огромного JSON. Синхронные LoadTextData/LoadAssetTables поддерживаются для совместимости. HasTextData проверяет только перечисленные адреса, но может загрузить TextAsset и не является проверкой без I/O.

## Время жизни и отмена

Провайдер принадлежит создавшему его коду. Менеджер не вызывает его Dispose автоматически. Все операции и Dispose выполняются на Unity-потоке; токен отмены можно отменять извне.

Dispose идемпотентен: запрещает новые чтения, отменяет ожидание незавершённых запросов и убирает список адресов. PendingLoadCount показывает незавершённые ожидания этого провайдера; после отмены продолжения могут закончиться на следующем обновлении Unity. Сам native ResourceRequest не прерывается, уже начатая загрузка может завершиться позже. Её результат не публикуется в менеджере.

Таблицы, TextAsset и связанные Unity-объекты заимствованы. Провайдер их не выгружает: ни при успехе, ни при ошибке, ни при Dispose. Поэтому закрытие одного провайдера не уничтожает объект второго менеджера или AudioSource игры. Уже подготовленные снимки и кэши остаются действительными; попытка нового чтения закрытого провайдера даст ObjectDisposedException. Внешний владелец не должен сам выгружать или менять ресурс, пока потребители им пользуются.

Это осознанно не native release. Unity Resources.UnloadAsset делает загруженный объект недействительным, поэтому вызывать его автоматически для общего ресурса здесь нельзя. [Документация Unity 6.0](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Resources.UnloadAsset.html).

## Границы набора

Отдельная невыбранная таблица не загружается. Но если выбранная таблица сама ссылается на большую текстуру, клип или SO с дальнейшими ссылками, эти зависимости остаются частью загрузки Unity. Для ограничения набора разделяйте большие категории на таблицы и выбирайте необходимые адреса. Набор не уменьшает размер билда Resources и не вводит бюджет памяти/вытеснение.

Автоматическая генерация списков через основное окно и управление native-ресурсами остаются последующими задачами. Внутренний генератор тестовой фикстуры и проверки находятся только в полигоне, за пределами UPM-пакета.
