# NS-DOC-011 — Диагностика ресурсов и исправления стенда

Редакция 1.0, 2026-11-17. Unity 6000.0.62f1, Windows. База `3ff7139` плюс изменения этого коммита; Night Shift 1.4.1. Этап 10 не начат.

## Как пользоваться

В основном окне **Simply Localize → Diagnostics → Resources** нажать **Refresh**. Конфиг выбирать не обязательно: панель показывает подготовленные наборы всех `LocalizationContext` текущего Editor. Обычный старый `LocalizationManager`, внешние ссылки игры и ресурсы другого Player здесь не учитываются.

Сверху — контексты, выбранные языки, состояние подготовки/закрытия, число ожидающих запросов и длительности. Ниже — поиск и список загруженных объектов. Выберите объект: появятся контексты-владельцы, политика Owned/Borrowed, язык и адрес загрузки. Выбор сохраняется при обновлении, пока объект остаётся в списке. Число владельцев относится к подготовленным наборам: во время переключения языка у одного контекста может быть старый набор и новый кандидат.

**Auto refresh (1s)** включает обновление раз в секунду. По умолчанию обновление ручное; после закрытия вкладки её опрос прекращается. **Record history** включает последние 256 событий; при переполнении старые удаляются, счётчик показывает сколько. Настройка записи сохраняется в текущей сессии Editor, в том числе при Domain Reload. В обычном Player запись выключена, пока её явно не включит игра. **Clear history** очищает только журнал, не выгружает ресурсы.

История начинается с включения записи. Включённая позднее запись не восстанавливает прошлые события, но текущие живые ресурсы доступны сразу. `Released` означает закрытие набора, `BorrowedReleased` — снятие заимствованного владения, `Retained` — объект ещё удерживается другим набором. Только `Unloaded` фиксирует завершённый вызов `Resources.UnloadAsset`; даже это не обещает уменьшения RAM процесса. Ошибка/отмена подготовки также записывается.

Пример: вступление и уровень подготовили одну таблицу Radio. У клипа два владельца. После завершения вступления остаётся один, поэтому клип не выгружается. После закрытия уровня Owned-клип освобождается. Если игра использует Borrowed, закрытие не означает native-выгрузку. [Подробный пример и ограничения владения](OWNERSHIP_AND_DIAGNOSTICS.md).

## Расширение из игры

Не нужен компонент на сцене, reflection или форк. Название задаётся при создании контекста через `LocalizationContextOptions.DiagnosticName`. Из своего отладочного инструмента, на Unity-потоке:

```csharp
LocalizationResourceDiagnostics.RecordingEnabled = true;
var snapshot = LocalizationResourceDiagnostics.Capture();
foreach (var resource in snapshot.Resources)
    Debug.Log($"{resource.Name}: {resource.ReferenceCount} prepared sets");
// Позже, когда запись больше не нужна:
LocalizationResourceDiagnostics.RecordingEnabled = false;
LocalizationResourceDiagnostics.ClearHistory();
```

Снимок неизменяемый, содержит только значения и не держит Unity-объекты. Регистрация живых наборов использует слабые ссылки. Метаданные адреса/языка и идентификаторы ведутся при подготовке даже с выключенной историей; это небольшая дополнительная работа, а не обещание нулевой стоимости. `Capture` выделяет память для снимка, поэтому не следует вызывать его каждый кадр. Готовые чтения локализации не создают диагностических событий. Панель использует виртуализированные списки, не сканирует все объекты Unity и не принуждает GC или глобальную выгрузку.

Адрес/язык обозначают первый путь, через который объект попал в конкретный набор. Для зависимости это адрес её таблицы, не отдельный адрес в Resources. Это не перечень всех алиасов и не язык результата конкретного `ResolveAsset`: для последнего используйте результат самого resolve. Скрытые внешние ссылки диагностика не обнаруживает. Если игра потеряла контекст без `ReleaseAsync`, слабая регистрация не заменяет корректное закрытие и может уже не содержать подробностей владельца.

Существующие методы, данные и правила владения не изменены. Addressables/AssetBundle, оценка RAM, автоматическая выгрузка и оптимизация массового release (SL-013) не добавлены.

## Исправления Night Shift

- **NS-UI-001:** процедурные стрелки и галочки заменили пустые картинки TMP dropdown. Дополнительные текстуры не нужны; выбор языка работает прежним способом.
- **NS-UI-002:** при открытых настройках субтитры находятся справа от меню; при закрытии возвращаются в нижнюю центральную область. Субтитры не отключаются ради устранения пересечения.
