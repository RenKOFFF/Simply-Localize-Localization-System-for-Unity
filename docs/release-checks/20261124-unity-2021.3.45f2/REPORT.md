# Unity 2021.3.45f2 — чистая установка и Windows Player

Прогон `20261124-unity-2021.3.45f2`. На Windows x64 в редакторе 2021.3.45f2 проверен пакет `com.renkoff.simply-localize` 2.0.2, ревизия `fe7fd28`. Минимальная версия в манифесте остаётся 2021.3. Проверена указанная сборка редактора; ранние патчи этой линии и другие платформы требуют собственной проверки.

## Что воспроизвелось

На ревизии `0a4b414` Package Manager успешно установил пакет из Git, но сборка окна остановилась. В Unity 2021 поля перечислений и чисел находятся в пространстве имён редактора, события списков имеют прежние имена, а свойства форматирования выпадающих списков недоступны для присваивания. Исправление `be01b43` использует публичные конструкторы списков и подписывает обработчики на событие соответствующей версии. Имена каналов и наборов остаются видимыми, их значения по-прежнему содержат стабильные ID. [Событие выбора в документации Unity](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/UIElements.BaseVerticalCollectionView-selectionChanged.html).

При добавлении второго ключа после редактирования первого ключ записывался, но окно сообщало об ошибке. Оно успевало сменить выбранный ID до завершения редактирования предыдущей записи. Регрессионные тесты воспроизвели это во вкладках Translations и Assets также на 6000.0.62f1. После исправления `fe7fd28` обе вкладки позволяют последовательно добавлять и выбирать записи.

## Итоговый сценарий

1. Создан отдельный проект без Library и пользовательской конфигурации. Единственная прямая зависимость — Simply Localize по локальному Git URL с `?path=/src/SimplyLocalize#fe7fd28668d66f20a1828d7cd34c2d43eba1943c`. Lock-файл подтвердил источник Git и полную ревизию. Разрешены TMP 3.0.9, uGUI 1.0.0 и Newtonsoft JSON 3.2.1. В установленном пакете находятся каталоги Editor, Integrations и Runtime.
2. В окне Simply Localize создан конфиг. Во вкладке Translations добавлены английская и русская строки для `Diary/Intro`, затем второй ключ. Проверены отображаемое имя канала, сохранение его ID и выбор первой строки обратно через ListView.
3. Из сохранённой сцены собран обычный Windows x64 Mono Player с нулём ошибок сборки. В запущенной игре компонент LocalizedText показал «The door is locked» → «Дверь заперта» → «The door is locked». На всех шагах AudioSource сохранял ссылку на один и тот же английский клип. Использовались batchmode и D3D11. Проверка фиксировала значение компонента и ссылку на клип.
4. На основной Unity 6000.0.62f1 после переноса UI прошла 131 редакторская проверка. Оба новых теста добавления записей упали до исправления. После него отдельный прогон вкладок Translations и Assets прошёл 26/26, включая оба теста. Эти выборки частично пересекаются.

Локальные журналы финального прогона — `playgrounds/U21Final/TestResults/accept.log`, `player.log` и `Packages/packages-lock.json`. Проекты, кэш, сборки и журналы остаются вне Git. Публичная публикация пакета и прогон полного тестового полигона на 2021.3 в этот сценарий не входили.
