## Границы измерений

Новый Player доказывает отсутствие предварительно загруженных объектов фикстуры, но не очищает файловый кэш ОС. Сканирование FindObjectsOfTypeAll не загружает соседей; загрузка для положительного контроля выполняется последней. Пробник не вызывает native unload или GC; ClearCaches убирает только его управляемые ссылки после завершения измерений.

Profiler.GetRuntimeMemorySizeLong вернул 0; это значение не трактуется как отсутствие памяти. Большая текстура подтверждена объектом и размерами, экономия RAM не измерена. Async-подготовка включает ожидания обновлений Unity; сравнивать её полное время с длительностью прежнего синхронного вызова как «ускорение» нельзя. JSON-парсинг остаётся на главном потоке. Нагрузки тысяч/сотен тысяч ключей и зависимости внутри одной большой таблицы здесь не проверялись.

Счётчики providerReads — вызовы API наблюдаемого провайдера, не трассировка диска. Время Play не равно задержке физического звука. Лимит 60 FPS, маленький игровой мир, кадровые измерения с открытым меню; это не сертификат производительности. WebGL/IL2CPP и другие версии Unity не проверялись.

## Воспроизведение

Использовать сохранённый build.cs через Unity CLI в редакторе 6000.0.62f1, выбрав новые выходной каталог/receipt. Скрипт не перегенерирует игровые сцены. Фикстура уже сохранена в Resources/ScopedResourcesProbe; внутренний ScopedResourcesFixture.Create нужен только для её первого создания и отказывается перезаписывать папку.

Обычный запуск: --nightshift-benchmark --nightshift-report <новый JSON> -logFile <новый лог> -screen-width 1280 -screen-height 720 -windowed.

Отдельный процесс для границ загрузки: --scoped-resources-probe --scoped-resources-report <новый JSON> -logFile <новый лог> -screen-width 1280 -screen-height 720 -windowed. Не объединять два проверочных флага в одном процессе. Новые результаты сохранять с новым Run ID.

Исторические результаты не переписаны. В Git сохранены отчёты, код/данные и архивы; Player/Library/сборочные кэши не добавлены. Тесты и фикстуры находятся вне распространяемого src/SimplyLocalize.
