Настройка контекста — не подготовка всего контента. SetLanguage — время вызова плагина, без ручной подготовки шрифта. Play — не физическая задержка звука. Провайдерный read — не гарантированный физический read с диска. Unity/GC memory — не общий RAM/VRAM. Пики снимаются раз в кадр, короткие пики могут быть пропущены.
