# Исторический запуск: стенд с обходными мерами

Дата: 2026-11-16. Версия стенда тогда отсутствовала; задним числом версия 1.0 ему не присваивается.
Локализатор: package.json 2.0.2, commit d2f77957ee30e06309a8a16ffa7c876929ad6384 (2.0.2-5-gd2f7795). Во время работы над стендом runtime плагина не менялся.

Этот стенд сам вызывал ClearCaches/UnloadUnusedAssets, готовил аудиоданные/глифы, создавал менеджер-кандидат для текста и хранил отдельные словари подготовленного контента. PASS в его отчёте относится к такой интеграции, **не к плагину без компенсаций**.

- VALIDATION.md — неизменённый прежний отчёт, включая его формулировки.
- API-GAPS.md — прежний список ограничений.
- Verification — прежние JSON и проверки.
- sample-source.zip — исходники именно той версии стенда с данными.
- SHA-256 архива: 1efe7d48f39ce8b05eb0c086514b3299b90c6e38c2ed0af1d678716a0b25854e.

Полезное из этого запуска: отдельная проба корневого Resources.LoadAll<LocalizationConfig>("") показала 0 → 6 AudioClip(Unloaded) → 0 после принудительной очистки. Это доказательство лишней загрузки объектов, а не загрузки всех декодированных аудиоданных.

С 1.0.0 обходы удалены. Метрики разных протоколов нельзя сравнивать как ускорение/замедление плагина.
