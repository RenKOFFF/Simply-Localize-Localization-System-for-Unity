# Ограничения существующего API

Зафиксированы при переработке Night Shift. Это материал для развития плагина: его runtime и публичный API в этой работе не менялись.

| Наблюдение | Ограничение нынешнего полигона | Возможное развитие |
|---|---|---|
| Автоинициализатор ищет конфигурации через Resources.LoadAll<LocalizationConfig>("") по всему корню | В проверенном Player запрос попутно загрузил объекты всех 6 AudioClip из таблиц, хотя их аудиоданные остались Unloaded. Полигон очищает неиспользуемые ресурсы перед показом меню; первоначальная стоимость уже понесена | Адрес конкретной конфигурации или явная регистрация bootstrap, без сканирования всех Resources. Исправлять в плагине отдельной задачей |
| ILocalizationDataProvider синхронный; ResourcesDataProvider читает/разбирает весь текстовый раздел языка и fallback | Один небольшой текстовый набор. Task не устраняет блокировку внутри загрузки | Отдельная асинхронная подготовка, resident-only lookup, состояния готовности |
| GetAsset может впервые загрузить таблицы | Все тяжёлые обращения до публикации мира; воспроизведение читает сессию | Запрет скрытого I/O при resident lookup, диагностика загрузок |
| Прямые ссылки таблиц могут вовлечь ресурсы соседних записей | Отдельные таблицы участка/языка, очистка кэшей после разрешения набора | Каталоги по scope, адресуемые ссылки, анализ зависимостей сборки |
| ClearCaches убирает managed-ссылки, но не гарантирует освобождение native/audio/GPU памяти | Отсоединение потребителей, выгрузка сцены, Dispose сессии, UnloadUnusedAssets на переходе | Контракт владения, handles/leases, общие зависимости, диагностика удержаний |
| Нет результата разрешения ассета с языком выбранного варианта | SO с contentLanguage/containsText и текстурой | Resolve-result с происхождением, независимо от типа ресурса |
| Менеджер не готовит аудиоданные | LoadAudioData и ожидание Loaded для трёх реплик | Интеграция с аудиосистемой и рабочим набором ближайших реплик |
| Нет общей транзакции независимых каналов | Отдельный текстовый кандидат; тяжёлые каналы зафиксированы сессией | Явные контексты и транзакции подготовки; общий глобальный язык не обязателен |
| Неполные данные могут возвращать fallback или ключ | Необходимые ключи проверяются HasKey до публикации; тяжёлые записи проверяются на null | Coverage validation, строгий режим обязательного контента, происхождение текста |
| Профили и конфигурации прямо ссылаются на шрифты | Латиница/кириллица; общий динамический атлас может сохранять добавленные глифы | Владение шрифтовыми наборами, CJK/RTL-тесты, бюджеты атласов |
| Конструктор менеджера устанавливает статические флаги LocalizationLogger | Одинаковые флаги во всех конфигурациях образца; глобальный фасад не заменяется | Логирование уровня экземпляра |

Установленные файлы, загруженные Unity-объекты, распакованные аудиоданные, RAM процесса и GPU-память — разные показатели. Unity allocated memory не заменяет платформенный профилировщик RAM/VRAM. Streaming-аудио также нельзя считать целиком резидентным только по Loaded.

Корневой поиск проверен отдельной пробой после выгрузки мира: 0 AudioClip до запроса, 6 объектов со статусом Unloaded после него, 0 после UnloadUnusedAssets. Источник вызова: Runtime/Core/Localization.cs, FindResourceConfig; он вызывается из LocalizationAutoInitializer ещё до загрузки первой сцены. Обёртка провайдера полигона не видит этот глобальный вызов, поэтому счётчики её обращений не являются полной трассировкой I/O процесса.

Будущий загрузчик должен ограничивать набор активными областями и ближайшими диалогами, поддерживать ошибки, отмену, освобождение и версии каталога. Предзагрузка всего многогигабайтного языка не является решением.

Документация Unity: [AudioClip](https://docs.unity3d.com/6000.0/Documentation/Manual/class-AudioClip.html), [блокирующее поведение Addressables.WaitForCompletion](https://docs.unity3d.com/Packages/com.unity.addressables@2.7/manual/SynchronousAddressables.html). Addressables в образце не установлен.
