## Воспроизведение

Открыть полигон на Unity 6000.0.62f1. Через Unity CLI выполнить сохранённый build.cs, предварительно выбрав новый выходной каталог/receipt для следующего запуска. Скрипт использует существующие сцены и не вызывает генератор Upgrade. Затем запустить полученный NightShift.exe с --nightshift-benchmark --nightshift-report <новый абсолютный JSON> -logFile <новый абсолютный лог> -screen-width 1280 -screen-height 720 -windowed. Новые результаты сохранять с новым runId.

В исходниках стенда и runtime-архивах сохранены соответствующие .meta. Внутренние тесты/инструменты и отчёты остаются за пределами распространяемого src/SimplyLocalize. Player, Library и сборочные кэши в Git не добавлены.
