## Артефакты и воспроизведение

player.json содержит buildIdentity, побайтно по значениям совпадающий с build-identity.json. build.txt фиксирует успешную сборку без ошибок; build.cs — сценарий сборки без перегенерации сцен. Для повторения использовать новый Run ID и новую запись.
