## Что эти числа НЕ доказывают

Настройка контекста больше не включает подготовку всех клипов, а SetLanguage — ручной прогрев шрифта; сравнивать их с прежними worldPrepare/textPrepare как ускорение плагина нельзя. Первый и повторный языки различаются прогревом кэшей.

Play — стоимость вызова, не готовность аудио и не физический звук. Счётчик провайдера — не физическое дисковое I/O. Memory — Unity/GC, не общий RAM/VRAM. Пики снимаются раз в кадр. Null graphics и открытое меню исключают оценку реального GPU/FPS/управления. Гигабайтные наборы, CJK/RTL, долгий soak-test и сеть непрерывной трассировкой не проверены.
