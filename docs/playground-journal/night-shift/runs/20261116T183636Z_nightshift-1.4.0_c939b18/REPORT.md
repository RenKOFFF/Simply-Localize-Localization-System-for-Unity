## Изменения относительно 1.3.0

[Ранее](../20261116T172318Z_nightshift-1.3.0_5ec24d8/REPORT.md) провайдер загружал выбранные таблицы асинхронно, но заимствовал ресурсы и не готовил AudioClip. Теперь голосовой и визуальный каналы используют LocalizationContext с Owned и PrepareAudio=true. Плагин готовит аудио до Loaded, учитывает общих владельцев и освобождает ресурсы после последнего закрытия. HorrorVisualVariant объявляет текстуру через ILocalizationAssetDependencies; профиль и шрифт остаются общей конфигурацией.

Игра останавливает аудио, снимает подписки/текстуры, выгружает сцену и ждёт ReleaseAsync. Собственные словари клипов, ручной LoadAudioData, UnloadUnusedAssets и GC в стенде не добавлены. Текст меню сохраняет прежний синхронный путь. Сцены и авторские данные не перегенерированы. Settings проекта после сборки восстановлены из исходной побайтовой копии.

## Что закрыто и что не измерено

SL-005/006 исправлены для нового явно подключённого контекста. SL-012 получил ограничения источников, записей/символов и шаблонов; кэш ограничен активной цепочкой и одним кандидатом. Это не смена поведения всех старых менеджеров и не гарантия жёсткого RAM-бюджета. SL-002/004 остаются ограничениями главного потока JSON и прямых зависимостей внутри выбранной таблицы. SL-010 требует отдельной работы со шрифтами.

Подготовка теперь включает аудио, протокол изменён: длительности нельзя выдавать за ускорение относительно 1.3.0. Первый Play измеряет стоимость API, не физическую задержку звука. Маленький мир, лимит 60 FPS, кадровые измерения с открытым меню; пиковый наблюдённый кадр 2688.17 ms не изолирует локализатор. Unity allocator/managed counters не являются RAM процесса. FindObjectsOfTypeAll проверяет резидентные объекты, а не кэш файлов ОС. Profiler.GetRuntimeMemorySizeLong большого соседа вернул 0; это не доказательство нулевого потребления памяти.

Глобальная выгрузка и принудительный GC не применяются ни для очистки результата, ни для измерений. Внутренний тест контекста использует настоящий Resources.UnloadAsset из плагина. Неучтённые внешние потребители требуют Borrowed. Наборы 1k/10k/100k, скрытые графы шрифтов/материалов, WebGL/IL2CPP и другие Unity не проверялись.

## Воспроизведение

Собрать сохранённым [build.cs](build.cs) через Unity CLI в редакторе 6000.0.62f1, выбрав новый каталог/receipt. Он не перегенерирует сцены. Запускать флаги отдельно, каждый раз новым процессом и с новыми JSON/log:

- --nightshift-benchmark --nightshift-report <JSON>
- --context-lifecycle-probe --context-lifecycle-report <JSON>
- --scoped-resources-probe --scoped-resources-report <JSON>

Общие аргументы: -logFile <log> -screen-width 1280 -screen-height 720 -windowed. Для автоматизации процесс запускается скрыто; ввод пользователя не захватывается. [Ручные сценарии](../../../../context-lifecycle/MANUAL_TESTS.md).

Сохранены отчёты/логи/exit codes, build identity, зависимости, архивы исходников и проверка их хешей. Player, Library и сборочные кэши не включены в Git. Тесты и генераторы остаются вне src/SimplyLocalize. Исторические запуски не изменены.
