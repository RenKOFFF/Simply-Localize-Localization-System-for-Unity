# Как пользоваться окном Simply Localize

Описывает текущую реализацию, а не предложение изменить архитектуру.

## Три разных решения

| Настройка | За что отвечает | Пример |
|---|---|---|
| Config | Общая настройка локализации проекта | Один LocalizationProject |
| Channel | Выбор языка, доступные языки и fallback | Main — русский, Voice — английский |
| Content set | Состав данных, которые нужны и загружаются вместе | Common, Chapter 1, Chapter 1 Voice |

Канал не является типом данных. Имя Voice не означает «только AudioClip».
Набор также может содержать и текст, и ассеты. Тип Text/Asset задаётся записи;
конкретный тип Unity-объекта проверяется при типизированном получении ассета.
Набор — логическая единица загрузки, не AssetBundle и не папка на диске.

Запись принадлежит набору. Канал подключает наборы и читает их на своём языке.
Один набор можно подключить к нескольким каналам. Это общие записи и источники,
а не независимые копии: редактирование русского перевода в таком наборе видно
везде, где используется тот же набор и русский язык.

## Маленькая игра

Достаточно Main/Common. В Common могут лежать надписи, картинки и несколько
звуков. Не нужно создавать канал для каждого типа Unity-объектов.

1. В Setup создать конфиг, выбрать языки, default и fallback.
2. В верхней части окна выбрать этот Config, канал Main и набор Common.
3. Во вкладке Translations добавить ключ, заполнить переводы, сохранить.
4. Во вкладке Assets работать с локализованными объектами.
5. Languages управляет доступностью языков, default и fallback выбранного канала.

## Независимая озвучка и большие объёмы

В Settings → Channels создать Voice, выбрать Independent. Во вкладке Languages
оставить в нём только реально поддерживаемые языки озвучки и настроить fallback.
Main может поддерживать больше языков, чем Voice. FollowMain используется, если
отдельный канал должен следовать основному выбору языка.

В Settings → Content sets создать набор, например Chapter 1 Voice. В Channels
подключить его к Voice. Load at startup нужен для постоянно доступных данных;
содержимое главы обычно подключается игровым кодом на время главы через API
наборов. Само создание набора в окне не добавляет этот вызов в игру.

В Content sets → нужный набор → Connect a source подключаются источники для
языков: JSON для текста и LocalizationAssetTable для объектов. Для Resources
можно указать сам ассет; адрес вычисляется из пути. Create empty JSON создаёт
и подключает новый текстовый источник. Несколько источников допустимы; если
мест назначения несколько, редактор предлагает явно выбрать Write to.

После этого сверху выбрать Channel и Content set и редактировать содержимое
через Translations/Assets. Выбор канала в редакторе не переключает язык игры.
Для внешнего редактирования JSON после изменений доступен Reload from disk.

## Можно ли добавить текст в Voice?

Да. Технически текст добавляется в выбранный набор, подключённый к Voice.
Для сохранения перевода нужен текстовый источник соответствующего языка.
Если в наборе настроены только таблицы объектов, сначала нужен JSON-источник.

Это полезно, например, для дословной расшифровки произносимой английской реплики
в обучающей игре, когда меню работает по-русски. Такой текст должен следовать
языку Voice. Обычные переведённые субтитры, которые должны оставаться русскими
при английском голосе, нужно читать через Main либо отдельный канал субтитров.

Добавление записи само по себе не выводит её на экран: компонент или код
должен запросить нужный канал, набор и запись.

Цена смешанного набора — совместный срок использования его источников.
Если аудио не нужно там, где используется текст, лучше разделить наборы.
Не следует считать, что запрос одной строки гарантирует загрузку только этой
строки: загрузка источников организована на уровне подключаемых наборов.

## Аудиодневник с английским голосом и переводными субтитрами

Если запись всегда одна и та же, самый короткий путь — назначить английский
AudioClip обычному AudioSource. Для субтитров добавить текстовый ключ
`Diary/Intro` в Main/Common и заполнить en и ru. Игрок услышит ту же запись
при любом языке интерфейса. Игровой код запускает звук и показывает субтитр.

Если озвучкой тоже управляет Simply Localize, например для подключения записей
при открытии дневника, настройка выглядит так:

1. Открыть Window → Simply Localize → Localization Editor. В Settings → Content sets
   создать DiaryAudio и DiarySubtitles. В Channels подключить DiarySubtitles к Main,
   добавить канал Voice в режиме Independent и подключить к нему DiaryAudio.
2. Выбрать Voice в верхней части окна. В Languages установить en как Default
   и Fallback, затем оставить доступным только en. Для Main включить en и ru.
3. Создать таблицу в папке Resources через Create → SimplyLocalize → Asset Table.
   В Settings → Content sets → DiaryAudio → Connect a source выбрать en,
   указать таблицу в Resources asset и нажать Connect source. В контексте
   Voice → DiaryAudio открыть Assets, добавить ключ через Add key, назначить
   английскую запись в Direct asset и нажать Save entry.
4. В DiarySubtitles → Connect a source выбрать en и нажать Create empty JSON.
   Повторить для ru с другим файлом. В контексте Main → DiarySubtitles открыть
   Translations и добавить один ключ `Diary/Intro`. Ввести «The door is locked»
   для en и «Дверь заперта» для ru, затем нажать Save entry.
5. Для простой проверки включить Load at startup у обеих привязок. В сцене
   привязать Localized Audio Clip на объекте с AudioSource к английской записи,
   а локализованный текст — к записи Diary/Intro через Main. При загрузке по
   требованию игровой код подключает оба набора при открытии дневника.

Проверка в игре: при Main = ru на экране «Дверь заперта». После смены Main на en
на экране «The door is locked». В обоих случаях используется один английский клип.

## Недостаток текущего интерфейса

Окно показывает Translations и Assets для любого канала. Имя Voice создаёт
ожидание аудиоканала, но UI не подчёркивает отсутствие ограничения и недостаточно
заметно объясняет общие наборы. Это проблема понятности интерфейса.

Возможное улучшение для согласования: заметная подпись назначения канала,
состав и пользователи набора, а при необходимости явное ограничение допустимого
содержимого набора. Ограничение нельзя выводить из имени Voice: названия
пользовательские, а смешанный контент имеет полезные сценарии. Такое поведение
пока не реализовано и не добавлено в согласованный план автоматически.
