# C7 — один демонстрационный стенд

Night Shift открывается со сцены `Assets/HorrorLab/NightShiftMenu.unity`.
В списке сцен сборки следом идёт мир `Assets/HorrorLab/NightShift.unity`.
Маленькая демонстрация, её генератор, контроллер кнопок, четыре старых ассета
настроек, демонстрационный шрифт и три JSON удалены вместе с их метаданными.
Последняя версия демонстрации и её старый протокол доступны в коммите `7006473`.

## Где теперь проверять прежние сценарии

| Сценарий маленького полигона | Независимая проверка в Test Runner |
|---|---|
| Видимый текст, именованный параметр и склонение при смене en/ru/pl | Два PlayMode-варианта `ChannelComponentTests.FormattedLabelKeepsArgumentsWhenTheLanguageChanges` создают TMP и legacy Text в памяти и проверяют строки после смены языка и количества. |
| Экранирование, параметры и язык отсутствующего перевода | `FormattingTests`, `ChannelFormattingTests` и `LocalizationRefreshTests` проверяют синтаксис, язык найденного шаблона и вывод компонента. |
| Оформление, повторная активация и исходный размер шрифта | `ProfileOverrideTests` проверяет TMP и legacy Text после Reload, переключения языка и повторного включения. |
| Кэш, обновление компонентов, уведомления и отказ провайдера | `LocalizationRefreshTests` и `ChannelLoadingTests` проверяют отображаемые значения, совместную публикацию текста и ассетов и количество событий Reload. `ChannelRuntimeTests` проверяет сохранение предыдущего состояния после ошибки. |

До удаления поиск по GUID обнаружил только одну внешнюю ссылку на данные старого полигона — стартовую сцену в EditorBuildSettings. После её удаления поиск по всем 25 GUID в оставшихся отслеживаемых файлах проекта и пакета дал ноль совпадений.

## Проверка на Unity 6000.0.62f1

- PlayMode прошёл 75 из 75 тестов, включая оба варианта новой проверки.
- В первом полном прогоне EditMode прошли 811 из 830 тестов. Все 19 сбоев относятся к двум классам проверок транзакций редактора. В 18 сообщениях Mono не смог открыть временный файл; один тест получил пустую ссылку на новый ассет. Например, абсолютный путь к файлу резервной копии занимал 267 символов. Это ограничение глубоко вложенных проектов в проверенной среде Windows следует учитывать при диагностике ошибок сохранения.
- В короткой копии проекта повторены оба затронутых класса: 38/38 прошли. Сопоставление результатов по именам тестов подтвердило успешный повтор каждого из 19 сбоев. Одного полного зелёного EditMode-прогона в длинной копии не было.
- В копии проекта с чистым импортом Unity разрешила все 775 проверенных ссылок. Проверка открыла все три сохранённые сцены, включая стандартную SampleScene, и проверила компоненты на отсутствующие скрипты.
- Windows x64 Player собран по двум включённым сценам из EditorBuildSettings. В Player прошли 203 проверки Night Shift. Отчёт сохранил прежнее наблюдение SL-008 о возврате ключа при отсутствующем переводе.
- Отдельный пустой проект через Git/UPM установил пакет ревизии `7006473` и создал стартовый конфиг для en и ru. Эта ревизия содержит те же исходники пакета, что и результат C7. В пакете присутствуют каталоги Runtime, Editor и Integrations.

XML, отчёт Player и логи находятся локально в `playgrounds/C7/TestResults`.
