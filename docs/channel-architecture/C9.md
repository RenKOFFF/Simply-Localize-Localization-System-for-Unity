# C9 — приёмка одного конфига с каналами

Исходники распространяемого пакета проверены на ревизии `2e91cf0` (UPM-подкаталог `src/SimplyLocalize`). Изменения стенда находятся отдельно. Для выпуска доступны [инструкция обновления](UPGRADE.md) и [руководство по окну](WINDOW_GUIDE.md).

## Сценарии

| Ситуация | Проверка |
|---|---|
| Одна английская запись, русский и английский текст | В пустом проекте через окно создан конфиг и ключ `Diary/Intro`. В собранной игре компонент LocalizedText обновил строки при en → ru → en. Во всех трёх состояниях AudioSource сохранил тот же английский клип. |
| Независимый дубляж и таблички | Night Shift переключает язык текста в открытом мире. Выбранные каналы Voice и Visuals сохраняют свои наборы и язык. |
| Два пользователя одних данных | Два экземпляра runtime разделяют физический клип. После освобождения первого второй читает тот же клип; после последнего освобождения нативный объект исчезает. |
| Большая таблица и сторонний провайдер | 4 096 ключей, английский заполнен целиком, русский наполовину. Два runtime читают один источник. Тест проверяет 8 192 значения, включая fallback, и неизменное число запросов к провайдеру во время чтения. |
| Граница C5-I01 | Допустимы индексированные параметры 0–65 535. Слишком большой сериализованный индекс игнорируется до выделения памяти, корректные соседние параметры сохраняются. Явный вызов SetArg с недопустимым индексом выбрасывает ArgumentOutOfRangeException. |

В трёх чистых проектах lock-файлы подтвердили установку по Git и отсутствие `com.unity.modules.assetbundle`. Пакет содержит пользовательские Runtime/Editor/Integrations. Тесты и генератор стенда остаются снаружи. Варианты с модулем Asset Bundle и без него ранее проверены в [C6](C6.md). Пакет сохраняет текущие зависимости TMP.

Минимальная версия в package.json — Unity 2021.3. В этой среде установлены три проверенных редактора Unity 6. Совместимость с 2021.3, iOS/macOS и физическое воспроизведение звука остаются открытыми для проверки. Публичная публикация в OpenUPM в этот прогон не входила.

## Результаты на основной версии

24 ноября 2026 года на 6000.0.62f1 прошли **831/831 EditMode** и **77/77 PlayMode**. Ошибок, пропусков и неопределённых результатов — ноль. Пройдены повторный вход в Play с Domain Reload, без него и с одновременно выключенным Scene Reload. Для EditMode использовалась короткая рабочая копия. Ограничение длинных путей транзакций редактора на Windows по-прежнему описано в [C7](C7.md).

В трёх отдельных запусках Development Player прошли 203 игровые проверки, 1 153 проверки жизненного цикла и 27 проверок выборочной загрузки. В последнем сценарии соседняя текстура 2048×2048 осталась незагруженной при подготовке выбранных таблиц. Сохраняется наблюдение SL-008 о выводе ключа при отсутствующем переводе.

## Сколько памяти заняла озвучка

Отдельный повтор в свежем Windows x64 Development Player, D3D11, после окончания других сборок. Один и тот же набор радио прошёл 20 циклов. Число клипов взято из загруженных AudioClip, объём — сумма Profiler.GetRuntimeMemorySizeLong для этих объектов, ссылки и языки владельцев — из диагностики Simply Localize. Все 20 повторов дали одинаковые результаты по клипам и ссылкам.

| Фаза | Клипы | Ссылки владельцев | Память объектов AudioClip, байт |
|---|---:|---:|---:|
| Старт цикла, набор закрыт | 0 | 0 | 0 |
| Открыт английский набор | 3 | 3 (en) | 885 086 |
| Выбран русский, английский подготовлен для fallback | 6 | 6 (ru и en) | 1 986 230 |
| После освобождения набора | 0 | 0 | 0 |

На этих данных основной язык и подготовленный fallback занимали память одновременно. В сценарии с двумя runtime первый владелец мог выйти во время использования клипа вторым. Родной объект Unity освобождался после выхода второго. Это проверка стандартного провайдера Resources с явным владением.

Unity allocated на первом старте — 56 743 810 байт, наблюдаемый пик — 58 904 948, после последнего освобождения — 56 743 602. Managed used соответственно 3 645 440, 4 141 056 и 4 128 768 байт. В managed-памяти остаются в том числе 80 строк самого измерителя. Принудительного GC в сценарии нет. Размер рабочего набора процесса и распределение всех managed-объектов по владельцам здесь не измерялись.

Пик счётчика Main Thread — 5,342 мс. В фазах «старт / en / ru с fallback / освобождено» центральные значения доступных замеров предыдущего кадра составили 0,184 / 0,136 / 0,185 / 0,101 мс (для чётного числа отсчётов взято нижнее центральное). Счётчик охватывает весь кадр игры. Замеры раз в кадр могут пропускать короткие пики аллокаций. Для оценки конкретной игры существенны размер её таблиц, формат аудио и выбранный провайдер.

XML, JSON и логи оставлены локально в `playgrounds/C8s/TestResults`. Полный EditMode — `edit.xml`, итоговый PlayMode — `accept-play.xml`, отдельный замер — `memory-final.json`.

## Как повторить

1. Открыть отдельную короткую копию проекта Night Shift на Unity 6000.0.62f1. Запустить все EditMode и PlayMode тесты. PlaySessionResetTests сами переключают настройки Domain Reload и восстанавливают их.
2. Собрать проверочную версию и запустить три отдельных процесса по [README стенда](../../playgrounds/SimplyLocalize-Lab/Assets/HorrorLab/README.md). В JSON сценария context-lifecycle массив `memorySamples` содержит четыре фазы каждого из 20 циклов. При проверке использовать один backend и одни исходные аудиофайлы.
3. Для чистой установки в пустом проекте добавить Git URL с `?path=/src/SimplyLocalize#<ревизия>`. В окне создать конфиг en/ru и стартовую запись, назначить LocalizedText на подпись, английский клип — на AudioSource. Собрать сцену и проверить значения после en → ru → en.
