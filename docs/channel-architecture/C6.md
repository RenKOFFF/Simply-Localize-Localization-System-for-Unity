# C6 — единый конфиг данных Night Shift

Статус: начат как зависимость удаления старого движка в C4. Полная приёмка C6
ещё не завершена; это не завершение нового окна C5 или нового стенда C8.

## Сохранённые данные

- `Assets/HorrorLab/Data/LocalizationProject.asset` — один проектный конфиг.
- Main/Common содержит текст; независимые Voice и Visuals подключают наборы
  Precinct Voice и Precinct Visuals только на время открытого мира.
- Зарегистрировано 20 существующих источников: 15 JSON, две голосовые таблицы,
  три визуальные таблицы. Переводы, WAV и PNG не переписывались.
- Языки: Main и Visuals — en/ru/pl, Voice — en/ru; fallback — en.
- Все три прежних оформления использовали один шрифт и стандартную типографику.
  Новый источник `NightShift/Appearance/Common` выражает это явно; конфиг хранит
  его адрес, а не прямые ссылки на шрифт и атлас.
- Визуальный вариант хранит `contentLanguage` как строку. Девять существующих
  ассетов обновлены явно без изменения GUID. Картинка больше не ссылается на
  LanguageProfile со шрифтом. Польская Warning по-прежнему берётся из en.
- Проверены хэши 181 существующего файла JSON/WAV/PNG/.meta внутри HorrorLab:
  после настройки изменений не было. Новые .meta относятся только к новым данным.

Сцена меню явно передаёт конфиг в свой runtime; AutoInitialize отключён.
Это обычный вариант явного bootstrap, а не альтернативный фиксированный адрес
автозапуска пакета. Простой проект по-прежнему может использовать автоматический
путь `Resources/SimplyLocalizeSettings.asset`.

## Работа приложения

HorrorApp владеет одним LocalizationRuntime. Настройки игрока выбирают язык
соответствующего канала. Меню держит только Common; выбор голоса/картинок до
входа не грузит контент мира. Подготовка мира выбирает языки пустых каналов,
затем получает два `LocalizationSetLease`.

HorrorWorldSession хранит регистрации наборов и использует готовые чтения.
Закрытие сначала отсоединяет аудио и материалы, затем освобождает регистрации.
Ошибка второго набора освобождает уже загруженный первый. Отмена дожидается
позднего результата провайдера. Runtime остаётся жив для меню и следующего мира.
Изменение Main не перезапускает независимый голос и не меняет визуальный снимок.

HorrorTextService пока остаётся адаптером представления над Main, без своих
словарей, форматтера или загрузчика. Ручное применение оформления и построение
HUD кодом ещё должны быть заменены обычными компонентами/сценой в C8.
Метрики и fault injection также ещё требуют отделения в dev-сборки.

Старый генератор геометрии/нескольких конфигов удалён: сохранённая сцена является
исходником стенда. Команда Open Night Shift открывает её. Configure Night Shift
Channels настраивает конкретные данные этого демо; это не мигратор пользовательских
конфигов и не часть устанавливаемого UPM-пакета. Повторный вызов использует
сохранённый конфиг и его ID.

## Проверки и оставшаяся работа

Пять PlayMode-сценариев Night Shift прошли: два прежних UI-сценария и три новых:

1. Один runtime; пустые тяжёлые каналы в меню; независимая смена текста;
   правильный fallback картинки; освобождение аудио после выхода.
2. Ошибка визуального источника после подготовки голоса; отсутствие оставшихся
   регистраций, сохранение меню и успешная повторная попытка.
3. Отмена при задержанном результате источника; ожидание его очистки и
   освобождение обоих наборов.

После удаления старого движка полный PlayMode-прогон — 73 passed, EditMode —
525 passed, без ошибок/пропусков. Результаты локальные, вне Git.

После завершения C5 удалены неиспользуемые TextConfig, VoiceConfig, ArtConfig
и три прежних LanguageProfile-ассета Night Shift вместе с `.meta`. Поиск GUID
и строковых путей не обнаружил внешних ссылок; после удаления ссылок на эти
GUID в Assets, ProjectSettings и src нет. Переводы, игровые сцены и новый конфиг
не менялись. Четыре legacy-ассета маленького стенда ещё связаны с его сценой;
их вывод остаётся в C7. Подробности очистки: [политика артефактов](../ARTIFACT_POLICY.md).

Новая модель окна C5 завершена. Добавлена [инструкция по окну](WINDOW_GUIDE.md),
объясняющая каналы, наборы и смешанные данные. Остались проверка чистой установки,
инструкция обновления пользователя и окончательная приёмка сборки/Player.
Очистка данных сама по себе не закрывает C6.

### Отдельные Player-проверки

Windows x64 Release / Unity 6000.0.62f1, Direct3D11, Radeon RX 6600,
`-batchmode` без `-nographics`. Все три процесса завершились успешно:

| Сценарий | Утверждений | Результат |
|---|---:|---|
| Жизненный цикл ресурсов | 1073 | Два владельца; 1000 готовых чтений без I/O; последний release; 20 переключений без накопления AudioClip; отмена и пользовательский граф зависимостей |
| Границы источников | 27 | Точные источники, fallback, соседний тяжёлый ресурс, Borrowed и закрытие ожидающей загрузки |
| Night Shift | 203 | Три входа/выхода мира, 18 комбинаций языков, независимость текста/голоса/картинок, отмена/ошибка/повтор, отсутствие чтений при первом подготовленном диалоге |

Два предупреждения Night Shift намеренно вызваны неверным языком и инъекцией
ошибки. SL-008 фиксирует сохранённое поведение: неизвестный ключ возвращается
буквально; это не новая ошибка перехода на каналы. Локальные отчёты:
`TestResults/Channels-C6/player-{lifecycle,scope,nightshift}-batch.json`.
В идентичности записаны commit базы, dirty-состояние и хэши проверенных исходников;
это не сборка неизменённого родительского коммита.

Обычный скрытый запуск без batchmode не дошёл до сценария: после 130 секунд
лог оставался на Windows Gaming Input, отчёт не появился. Только этот тестовый
процесс был остановлен. Поэтому обычный интерактивный запуск ещё требует
отдельной проверки; batchmode-PASS не маскирует эту проблему окружения/запуска.
Счётчики объектов доказывают конкретную выгрузку, но не заменяют baseline/peak/
settled памяти, стоимость главного потока и проверку физического звука из C9.
