# C4: карта переноса регрессий

Проверки переводятся на публичный `LocalizationRuntime`, а не на совместимую
обёртку старого менеджера. Число тестов меняется: параметризованные случаи могут
быть объединены в один сценарий, прежняя последовательность Prepare/Apply
заменена одной атомарной операцией. Ниже указаны сохранённые гарантии и намеренно
изменённые ожидания. Это не заявление о завершении C4 или редакторского C5.

## Сохранённое покрытие

| Прежняя группа | Новая группа | Что проверяется |
|---|---|---|
| LocalizationContextTests | ChannelResourceLimitsTests | Лимиты записей/размера источника, ограниченный кэш форматирования, отмена, drain при закрытии, ошибки наблюдателей, замороженные параметры, повторные переключения, запрет Owned Resources в EditMode |
| AssetOnlyContextTests | AssetOnlyChannelTests | Набор только ассетов, Reload и замена провайдера без чтения текстов, ошибка сохраняет готовое состояние, явный отсутствующий источник, пустой набор без сканирования |
| LocalizationContextPlayModeTests | ChannelOwnershipTests | Настоящие Owned/Borrowed Resources, отмена, общее владение fallback, окончательное освобождение, лимиты, границы Play-сессии |
| PreparedLocalizationTests | ChannelSnapshotTests, ChannelRuntimeTests, SourceProviderTests | Готовые чтения без I/O, атомарность, удержание старого снимка, копии коллекций, ошибки/пустые результаты, отмена, поздняя очистка, освобождённые снимки, выбор вида источника, неизменяемые определения |

| Прямые вызовы менеджера в ConfigDiscoveryTests/DataDiscoveryTests/LifecycleDiagnosticsTests | Новый runtime либо публичная валидация авторинга | Явный конфиг вне Resources, отсутствие изменения живого снимка при Coverage, проверки старого редакторского формата без запуска старого движка |

Дополнительно:

- `ChannelRuntimeResourcesTests`: аудиокомпонент останавливается и отсоединяет
  клип до Owned-выгрузки; текст восстанавливает исходный шрифт до выгрузки оформления.
- `PlaySessionResetTests`: две реальные Play-сессии одновременно без Domain Reload
  и Scene Reload; новый runtime, закрытие прежнего, восстановление привязки текста.
  После границы Play/Edit тест получает актуальный компонент из сцены: сохранённая
  C#-обёртка Unity-компонента не считается доказательством его состояния.
- `ChannelRuntimeTests`: повторный выбор текущего языка не загружает и не
  уведомляет; он всё равно отменяет и дожидается очистки более раннего переключения.
  Отменённый токен остаётся отменой. `ReloadAsync` принудительно перечитывает источники.

## Изменившиеся контракты

| Старое ожидание | Новое поведение и проверка |
|---|---|
| Первый Get/HasKey после ClearCaches подгружает данные | Чтение никогда не делает I/O. До Initialize оно отклоняется; обновление — явный Reload. ChannelLoadingTests и PreparedResourcesTests |
| Пользователь вручную передаёт Prepare-результат в Apply, включая чужой/устаревший | Такого API нет. Публикация внутри runtime; latest-wins, независимость экземпляров и отмена — ChannelRuntimeTests |
| Отмена не ждёт неподдерживающий её источник | Task операции дожидается позднего результата и его очистки. ChannelSnapshotTests/ChannelRuntimeTests; это не гарантия, что зависший сторонний провайдер когда-либо завершится |
| Изменение ScriptableObject инвалидирует подготовку/активные кэши | Runtime замораживает определения. Reload обновляет содержимое источников; новый runtime принимает изменённую структуру. ChannelSnapshotTests/ChannelRuntimeTests |
| Async Resources не поддерживается без старого optional-интерфейса | Новый источник Resources действительно асинхронный. ExactResourceSourceTests, SourceProviderResourcesTests |
| Повторный ключ в файлах молча выигрывает по порядку | В одном наборе/языке конфликт отклоняется; прежний снимок сохраняется. ExactResourceSourceTests |
| Сравнение ключей определяется comparer словаря провайдера | Ключи имеют ordinal-идентичность; регистр не зависит от источника. ChannelLoadingTests |
| Неизвестный язык тихо игнорируется, null ничего не делает | Неподдерживаемое значение даёт исключение до отмены корректной операции; null означает настроенный default. ChannelLoadingTests/ChannelRuntimeTests |
| Цикл fallback допускается и обрывается обходом | Конфиг отклоняет цикл до создания runtime. ProjectConfigurationTests |
| Пустая запись существует для HasTranslation, но Get берёт fallback | Runtime сообщает найденное готовое значение и его язык через TryGetText; наличие исходной пустой записи — задача редакторских данных/coverage |
| Провайдер содержит общий Dispose для закрытия контекста | Runtime освобождает выданные lease; сам провайдер остаётся собственностью вызывающего. SourceProviderTests/ChannelLoadingTests |
| Скрытый thread-local scope менеджера меняет вывод общего логгера | Новый runtime не изменяет статические настройки. Общий info-лог включается явно; ошибки экземпляра наблюдаются через его ObserverError. RuntimeLoggingTests/ChannelRuntimeTests |

## Ещё не закрыто

Сравнение runtime fallback с предпросмотром старого `FallbackResolver` намеренно
не выдаётся за проверку нового окна: его замена и повторная проверка относятся
к C5. Там же проверяются наличие пустой исходной записи, Coverage и редакторское
обнаружение данных. Прежние редакторские проверки остаются до перевода Editor.

Основная сборка SimplyLocalizeTests, игровая обвязка и Player-сценарии больше
не вызывают старые менеджер/контекст или Prepare/Apply. Старый движок удалён.
Editor-регрессии пока используют старую модель авторинга и читатель
EditorResourcesDataSource в сборке Editor; их переход остаётся частью C5.

Редакторская фикстура ExactResourceSourceTests доказывает перечень запросов.
Она создаёт соседнюю таблицу через AssetDatabase, поэтому не доказывает, что
сосед никогда не находился в памяти. Нативное владение и выгрузка проверяются
отдельно в PlayMode. Размеры памяти процесса/пики и Player остаются приёмкой C9.
