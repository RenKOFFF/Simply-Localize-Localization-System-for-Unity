# C8 — стенд Night Shift

На Unity 6000.0.62f1 собраны обычная и проверочная Windows x64 версии из сохранённых сцен. В меню теперь хранится иерархия Canvas, кнопок, списков, подписей и панелей. Для изменения ширины меню или положения субтитров откройте сцену NightShiftMenu. Пересборка интерфейса из C# при запуске больше не требуется.

## Как этим пользоваться в своей игре

1. В окне Simply Localize создайте проект, выберите en и ru, добавьте ключ `Diary/Intro` и заполните обе строки. Оставьте набор стартовым в основном канале.
2. На текстовый объект добавьте `LocalizedText` и выберите ключ. Для фонаря, инвентаря или аудиодневника процедуру создания конфига повторять не требуется.
3. Из обработчика выбора языка вызовите `await Localization.SetLanguageAsync("ru")` после инициализации. Если нужен доступ к переводу в коде, используйте публичный API:

```csharp
var runtime = await Localization.InitializeAsync();
await runtime.SwitchLanguageAsync("ru");
string subtitle = runtime.Get("Diary/Intro");
```

Если английская запись одна для всех, назначьте клип в AudioSource. Русские и английские субтитры останутся в основном канале. Если игрок выбирает дубляж независимо, создайте канал Voice со своим списком языков. Набор реплик конкретной главы подключайте на время этой главы. Тот же подход работает для необязательных иллюстраций и табличек.

## Что проверяет Night Shift

У игры один конфиг и один runtime. Main обслуживает текст и подписи интерфейса. Перед входом в участок игра подключает наборы каналов Voice и Visuals. На выходе она останавливает воспроизведение, отсоединяет объекты сцены и освобождает регистрации. Обычные подписи сцены используют LocalizedText, динамический текст получает профиль через LocalizedProfileOverride. Разделение игровых скриптов и команды сборки описаны в [README стенда](../../playgrounds/SimplyLocalize-Lab/Assets/HorrorLab/README.md).

Пройдены 77 тестов PlayMode, включая переключение en/ru/pl, подпись из сохранённой сцены, раскрытие языкового списка, читаемость субтитров рядом с открытым меню, освобождение ресурсов и повтор после ошибки. Development Player прошёл 203 игровые проверки. При намеренно отсутствующем ключе возвращается сам ключ (ранее зарегистрировано как SL-008). В обеих сборках проверен состав Assembly-CSharp.dll. HorrorBenchmark, ContextLifecycleProbe, ScopedResourcesProbe и ObservedResourcesProvider присутствуют только в Development Player.
