#### 9.3 — готовность аудио, владение и лимиты — выполнен

Добавлен LocalizationContext: готовит выбранный язык/fallback и аудио до Loaded, проверяет лимиты, затем публикует новое состояние. Ошибка/отмена сохраняет прежний набор. По умолчанию ресурсы заимствованы (Borrowed); явный Owned включает общий учёт владельцев и Resources.UnloadAsset после последнего пользователя. Ожидающие запросы тоже удерживают объекты; отменённые поздние загрузки учитываются и очищаются. ReleaseAsync позволяет дождаться завершения. Пользовательские SO объявляют зависимости через ILocalizationAssetDependencies без форка пакета. Старые API, данные и поведение обычного ResourcesDataProvider сохранены.

Это не жёсткий лимит RAM: прямые зависимости Unity загружает вместе с таблицей. При отключённом Domain Reload новая сессия сбрасывает реестр; старые контексты не могут освободить ресурсы новой. Регрессия проверяет границу сессии через вызов reset; ручной многократный вход в Play без Domain Reload остаётся в сценариях приёмки.

## Принятые решения по загрузчикам

Resources остаётся встроенным вариантом. Addressables — будущая необязательная интеграция. Файловые языковые пакеты интересны для пользовательских переводов готовой игры (например, добавление игроком польского языка в настольной версии с itch.io): понадобятся обнаружение языка без Unity, метаданные пакета, проверка формата, fallback и поддерживающие символы шрифты. Это будущая возможность, в этап 6.1 она не входила; просто чтение JSON её полностью не решает.
