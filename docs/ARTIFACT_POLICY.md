# Что хранится в репозитории

Правила обновлены 2026-11-17 по просьбе автора. Они заменяют прежнее требование копировать полный комплект артефактов каждого запуска в `docs/runs`.

В Git остаются исходники, регрессионные тесты, необходимые тестовые ассеты и их `.meta`, инструкции и краткие проверяемые отчёты. Сохраняются также уникальные данные старых дефектов, которые нельзя восстановить из исходников: они нужны для воспроизведения, а не для обычного использования пакета. Тесты и стенд находятся в `playgrounds`, за пределами UPM-пакета `src/SimplyLocalize`.

Результаты обычного прогона JSON/XML, логи, PID, ответы команд, временные проверочные скрипты и скриншоты остаются локально в `playgrounds/SimplyLocalize-Lab/TestResults`. Собранные игры — в `Builds`. Эти каталоги игнорируются Git. В отчёт достаточно записать среду, проверенную базу/изменения, состав проверок, результат и ограничения. Уникальное доказательство новой ошибки можно сохранить отдельно, объяснив его назначение.

Не нужно дублировать уже закоммиченные исходники ZIP-архивом. `BuildIdentity.json` и его `.meta` генерируются перед сборкой стенда и также не коммитятся. Это данные конкретной сборки, а не ручная конфигурация игры. Каталог `Assets/HorrorLab/Verification` больше не используется для хранения результатов.

Из `context-lifecycle/20261116` удалены полные выводы обычных EditMode/PlayMode прогонов; результаты сохранены в отчёте. Из `manual-20261116` убраны одноразовые скрипты, служебные снимки состояния/хеши и дублирующие кадры меню. Сохранены сводные результаты, проверки владения/циклов/отмены, кадр обоих UI-дефектов и спорные кадры QA-CAPTURE-001. Эти 18 удалённых файлов занимали 5 923 392 байта.

Четыре результата из `Assets/HorrorLab/Verification` уже имеются в записи `20261116T123233Z_nightshift-1.1.1_d2f7795`; пятый сообщал только `not-measured-in-this-run`. Они и их `.meta` удалены. Генерируемый build identity исключён из Git. Полезные ассеты стенда, тесты и фикстуры не удалены.

Более старые архивы оставлены: некоторые фиксируют промежуточные dirty-версии, для которых пока не подтверждено полное соответствие Git. Их удаление потеряло бы возможность воспроизвести старое наблюдение. Удалять их можно после такой же проверки.

Это очистка текущего дерева, **не переписывание истории Git**: размер старых объектов `.git` от неё не уменьшается. Удалённый файл можно восстановить из родительской ревизии `3ff7139` командой `git show 3ff7139:<путь-в-репозитории>` либо из соответствующей исходной ревизии выше. Старые отчёты описывают комплект на момент запуска; заметка об очистке не меняет их измерений.
